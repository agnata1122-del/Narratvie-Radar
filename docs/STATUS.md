## 상태 구분

| 표시 | 뜻 |
|---|---|
| **운영 중** | 정기 실행(Actions)에서 실데이터로 돌고 있다 |
| **구현 완료** | 코드·자동 테스트가 있고, 실데이터로 끝까지 한 번 이상 돌려 결과를 확인했다. 정기 실행에는 들어 있지 않다 |
| **미검증** | 코드와 예시 데이터 테스트만 있다. 실데이터로 돌려 확인한 적이 없다 |
| **미구현** | 코드가 없다 (소스 등록·문서 설계만 있는 경우 포함) |

ROADMAP의 "완료"는 코드 완료를 뜻한다. 이 문서는 실데이터 검증 여부까지 구분하므로 같은 항목이 여기서는 **미검증**일 수 있다.

## 4. KIC 출품을 위한 기능 확장 (별도)

- 저장소 문서에는 KIC의 일정·심사 기준·제출물이 아직 없다. 이 절은 **PRD 범위를 바꾸지 않는다.**
- 출품 시연에 쓸 수 있는 것은 이미 PRD·ROADMAP에 있는 항목뿐이다: 첫 데모 목표("며칠 뒤 다시 열었을 때 무엇이 달라졌고 왜인지", ROADMAP), 그래프·시간 재생·달라진 점 화면(M8·M9), 가격 렌즈(M9.8). 이들은 모두 1장 기준 **미검증**이라, 시연 전에 실데이터 화면 확인이 먼저다.
- PRD 밖의 확장이 필요하면 소유자가 KIC 요구사항을 정한 뒤 DECISIONS에 기록하고 ROADMAP에 넣는다. 그 전까지 이 문서에 확장 기능을 적지 않는다.
