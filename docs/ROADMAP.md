## 체크포인트

1. **M3 이후**: 수집기가 24시간 연속으로 돌고, 누락률·스냅샷 재방문 성공률·공백 기록을 확인한다.
2. **M7 이후**: 명령줄만으로 수집 → 분류 → 그래프 → 위키 → 시점 복원이 끝까지 돌고, 평가 리포트가 나온다.
3. **M9 이후**: 브라우저에서 "달라진 점"과 시간 재생 화면을 스크린샷으로 확인한다.

## 시작 전에 필요한 것

- **네트워크 허용** (M2): 개발 환경에서 `jetstream1.us-east.bsky.network`, `jetstream2.us-east.bsky.network`, `hn.algolia.com`, `hacker-news.firebaseio.com`에 접속할 수 있어야 한다. 안 되면 확인 명령은 로컬 PC에서 실행한다.

### R1 우선 개선 대상: 관계 유형 오류 (E1 주장 표본·review에서 확인, 2026-10-18)

지침(finance.v2)에 이미 금지돼 있는데도 Haiku가 어기는 것들이다. 개선은 ① 자동 탐지 규칙으로 review 표시(관계를 지우지 않음) ② 지침에 오류 유형별 예시 추가(해당 글만 재분류) ③ 그래프 확장에서 해당 관계를 따라가지 않기, 순서로 검토한다.

| 오류 | 사례 | 탐지 단서 (안) |
|---|---|---|
| 비교 → 경쟁 | "CXMT to match Micron's DRAM capacity" → `COMPETES_WITH`; 가상의 신규 팹 vs 두 회사 | `COMPETES_WITH` + 비교 표현(than·vs·match·compared·bigger·cheaper)만 있고 경쟁 표현(compete·rival·threat·take share)이 없음 |
| 부품 → 소속 | `HBM PART_OF Apple silicon` | `PART_OF`의 주어가 `TECH:`·제품 부품. 소속은 지분·인수·사업부일 때만 |
| 공급 예정 → 확정 공급 | Stargate 웨이퍼 계약 → `Samsung SUPPLIES_TO OpenAI` | `SUPPLIES_TO` + 미래·계약 표현(will·deal·agreement·LOI·plan·up to·reportedly·예정·계약) |
| `RELATED_TO` 남용 | accepted에 6개, `Samsung RELATED_TO Micron` | `RELATED_TO`는 모두 review (지침상 금지) |
| 비공식 묶음 소속 | `Broadcom BELONGS_TO Mag 10` | `BELONGS_TO` 목적어가 지수·업종이 아닌 별칭 묶음 |
| 영향 과다 | `HBM AFFECTS Mi300x`(부품), `HBM AFFECTS DRAM`(용량 비교), `Micron AFFECTS Upstate NY`(위치) | `AFFECTS`인데 발췌에 영향·제약·가격 표현이 없음, 목적어가 `PLACE:` |
| 주어 오인 | 미국의 EUV 장비 금지 → `EUV AFFECTS HBM`; 경쟁사 전용 칩 → `HBM AFFECTS Nvidia` | 기존 "발췌 밖 주어·목적어" 탐지와 함께 사람 확인 |

R1 검증에서 같은 주장 표본 50개를 다시 보고 위 유형 오류가 줄었는지 확인한다(E1 판정과 별개).

교차 검토(Claude·ChatGPT) 뒤 우선순위 (그래프가 잘못된 관계로 퍼질 위험 순):

1. `SUPPLIES_TO`: 출하·공급 계약 이행·납품이 원문에 있을 때만. 보유("has GPUs"), 공급사 인증·선정, 업계 전반의 의존, 계약·LOI는 생략하거나 review. 새 기업으로 가지를 뻗는 주 경로라 위험이 가장 크다.
2. `AFFECTS`: 영향·제약·가격 변화를 말할 때만. 부품 관계, 성능·용량 비교, 위치는 생략.
3. 결과가 사건(종료·가격 상승·생산 감소)일 때: 개체에 `CLAIMED_CAUSE_OF`를 걸지 말고 `AFFECTS` + polarity로 방향을 남기거나 생략. "Micron이 Crucial의 원인" 같은 뜻 바뀜을 막는다.
4. 주어는 실제 행위자(정책·금지 조치 등). 기술 개체로 바꾸지 않는다.
5. `COMPETES_WITH`·`PART_OF`·`RELATED_TO`·`BELONGS_TO`는 위 표대로.
6. 주장 태도의 기준 대상 정의(그래프보다 N2에 영향).

### `finance.v2`에서 뜻이 불명확한 필드·관계 (2026-10-18 점검)

| 항목 | 불명확한 점 | 실제로 생긴 문제 |
|---|---|---|
| `claims[].stance` | 기준 대상 없음 ("이 주장만의 태도" vs "관심사 종목에 대해") | 두 AI 태도 판정 6 vs 17, N2 정의 불명확 |
| `claims[].polarity` | 공통 지침은 목적어 기준, 금융 팩은 관심사 종목 기준 (금융 팩이 우선이라 충돌) | `Nvidia AFFECTS AMD` constraint가 누구 기준인지 갈림 |
| `SUPPLIES_TO` | 출하 발표·공급사 인증·실제 납품·보유·의존·계약을 구분하지 않음 | #5·43·44·48, Stargate 계약 |
| `AFFECTS` | "영향을 준다"만 있음. 부품·비교·위치를 막는 문장 없음 | `HBM AFFECTS Mi300x`, `Micron AFFECTS Upstate NY` |
| `CLAIMED_CAUSE_OF` | 목적어가 개체뿐이라 결과 사건(종료·가격 상승·생산 감소)을 담을 수 없음 | #21·33 의미 축약, #37 의미 뒤바뀜 |
| `PART_OF` | "일부"가 소유·사업부인지 부품인지 구분 없음 | `HBM PART_OF Apple silicon` |
| `BELONGS_TO` | "분야·집단"의 범위 없음 | `Broadcom BELONGS_TO Mag 10` |
| `RELATED_TO` | 공통 지침은 허용, 금융 팩은 금지 | accepted에 6개 남음 |
| `COMPETES_WITH` | 금융 팩에 기준이 있으나 용량·계획 비교는 예시 없음 | CXMT 생산능력 추격 |
| `evidence_status` | `reported_fact`가 "보도 인용(확인 전)"인데, 전언·예측을 담은 보도와 구분 없음 | 예측 기사를 확정 사실처럼 읽힘 |
| 주어 | 행위자가 정책·조치일 때 기준 없음 | `EUV AFFECTS HBM` |

### R1 최소 규칙 제안 (지침 문장 + 자동 탐지, 스키마는 그대로)

1. `SUPPLIES_TO`: 원문에 출하·납품·공급 계약 이행이 있을 때만. 공급사 인증·선정·계약·LOI는 생략하고 필요하면 review("공급 확정 아님"). 보유·업계 의존은 생략. 탐지: 인증·계약·미래 표현 → review.
2. `AFFECTS`: 원문이 영향·제약·가격·수급 변화를 말할 때만. 부품·성능 비교·위치는 생략. 탐지: 목적어가 `PLACE:`, 발췌에 영향 표현 없음 → review.
3. 사건형 결과: 결과가 사건이면 `CLAIMED_CAUSE_OF`를 개체에 걸지 않는다. 방향이 원문에 있으면 `AFFECTS` + polarity, 아니면 생략. 탐지: `CLAIMED_CAUSE_OF` 목적어가 기업이고 발췌에 종료·인수·지연 등 사건어 → review.
4. 주어는 실제 행위자. 정책·금지·조치가 원인이면 그 조치를 주어로(키 없으면 생략).
5. `PART_OF`는 소유·사업부·자회사만. `BELONGS_TO`는 지수·업종·공식 분류만. `RELATED_TO`는 금융 팩에서 쓰지 않는다(탐지 → review).
6. `polarity`는 목적어 기준으로 통일(금융 팩 문장 정리). `claims[].stance`는 분석에 쓰지 않는다(N2 설계안 참고).
7. 그래프: 위 1–5로 review된 관계와 `RELATED_TO`·`BELONGS_TO`는 자동 확장 경로로 쓰지 않는다. 소유자가 정한 #5·#48 유형(직접 근거 없는 공급)도 같다.

검증: 같은 주장 표본 50개를 새 지침으로 다시 추출해 위 유형 오류 수를 비교하고, 탐지 규칙이 정상 관계를 얼마나 review로 보내는지(오탐률)를 함께 본다. E1 데이터는 바꾸지 않는다.

R1의 추출 개선은 [EXPERIMENTS.md](EXPERIMENTS.md) "R1-X 추출 규약 비교 실험"으로 검증한다(사건·인과 연결·근거 검증 단계 분리, 기존 그래프 구조 유지). N2′는 R1-X 다음.
