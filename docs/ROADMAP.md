## 체크포인트

1. **M3 이후**: 수집기가 24시간 연속으로 돌고, 누락률·스냅샷 재방문 성공률·공백 기록을 확인한다.
2. **M7 이후**: 명령줄만으로 수집 → 분류 → 그래프 → 위키 → 시점 복원이 끝까지 돌고, 평가 리포트가 나온다.
3. **M9 이후**: 브라우저에서 "달라진 점"과 시간 재생 화면을 스크린샷으로 확인한다.

## 시작 전에 필요한 것

- **Anthropic API 키** (M4): 클라우드 환경 설정에서 `ANTHROPIC_API_KEY`로 추가.
- **네트워크 허용** (M2): 개발 환경에서 수집 대상 도메인에 접속할 수 있어야 한다. 안 되면 spike는 로컬 PC에서 실행한다.
- **상시 수집 호스트** (M3): 항상 켜져 있는 PC나 소형 서버. 해외 IP 차단 여부를 M2에서 확인한 뒤 정한다.
