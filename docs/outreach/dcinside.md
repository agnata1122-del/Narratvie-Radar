# 디시인사이드 데이터 이용 문의 (초안)

**제목**: 미국주식갤러리 게시글 분석용 데이터 이용 가능 여부 문의

안녕하세요. 개인 연구 목적의 웹 서비스를 개발하고 있는 [이름]입니다.

미국주식갤러리에서 특정 종목(NVIDIA)에 대해 어떤 이야기가 오가고, 그 논점이 시간에 따라 어떻게 바뀌는지를 분석하는 도구를 만들고 있습니다. 귀사 이용약관이 자동화된 수단에 의한 콘텐츠 수집을 금지하고 있어, 허락을 받을 수 있는 방법이 있는지 여쭙고자 연락드립니다.

**이용하려는 데이터**

- 미국주식갤러리 게시글의 제목, 본문, 작성 시각, 댓글 수, 조회 수, 추천 수
- 댓글 본문 (가능한 경우)
- 작성자 닉네임·아이디·IP는 저장하지 않습니다. 같은 작성자를 구분할 필요가 있을 때도 되돌릴 수 없는 해시값만 사용합니다.

**이용 방식**

- 읽기만 하며, 글쓰기·추천 등은 하지 않습니다.
- 요청 간격은 최소 3초 이상, 동시 요청 1개로 서버에 부담을 주지 않겠습니다. 원하시는 빈도나 시간대가 있으면 따르겠습니다.
- 수집 프로그램임을 밝히는 User-Agent를 사용하고, robots.txt를 따릅니다.
- 중단을 요청하시면 즉시 멈추겠습니다.

**이용 목적과 범위**

- 게시글을 주제별로 묶고 시간에 따른 논점 변화를 시각화하는 개인 연구용 프로토타입입니다. 현재 상업적 이용 계획은 없습니다.
- 원문 전체를 다시 공개하지 않습니다. 화면에는 짧은 발췌와 요약, 원문 링크만 표시합니다.
- 인공지능 모델 학습에는 사용하지 않습니다. 분류와 요약에만 사용합니다.
- 상업적 이용을 하게 되면 그 전에 다시 협의하겠습니다.

**여쭙고 싶은 것**

1. 위 범위의 데이터 이용을 허락받을 수 있는지
2. 공식적인 데이터 제공 방법(API, 제휴 등)이 있는지
3. 허락하신다면 지켜야 할 조건(빈도, 보관 기간, 표기 방식 등)

검토해 주셔서 감사합니다.
