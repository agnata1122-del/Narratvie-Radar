# 데이터 이용 문의

두 회사에 보낼 문의 메일 초안이다. 발송은 프로젝트 소유자가 직접 한다.

| 파일 | 대상 | 보낼 곳 |
|---|---|---|
| [dcinside.md](dcinside.md) | 디시인사이드 | 사이트 하단의 제휴·광고 문의 또는 고객센터 |
| [naver_pay_securities.md](naver_pay_securities.md) | 네이버페이 증권 | 네이버페이 고객센터의 증권 서비스 문의 또는 제휴 제안 창구 |

담당 창구 주소는 이 개발 환경에서 확인하지 못했다. 각 사이트에서 직접 확인한다.

보내기 전에 `[ ]` 표시를 채운다. 회신을 받으면 결과를 [../DATA_POLICY.md](../DATA_POLICY.md)의 "확인 결과"에 적고, 허락 조건이 있으면 수집기 설정에 반영한다.
